# XXD Shop 记住的交付偏好

本次调用解析完用户的描述和行内参数后，仍有交付设置未确定时，按本文件处理。目的是少问重复问题，同时不让上一次任务的商品、事实或审美污染这一次。

## 记住什么

整个 XXD Shop 家族共用一条“上次交付”记录，只能包含：

- 尺寸策略、比例或准确像素；
- 每件商品每个尺寸的张数；
- 文字方式与目标语言；
- 用户明确选过的输出根目录。

永远不记：商品图、图片路径、商品名称、品类、用途、事实、价格、准确文案、文件名到文案的映射、Logo、参考图、所选编号、生成的提示词、成品路径、任务名、模型／供应商／端点、凭据、账户或任何密钥。`text_mode=exact` 或 `plan` 可以记，但文案本身不记，下次必须重新输入。

记住偏好不等于复用旧成品。每次调用都新建任务、重新生成，每个编号士兵仍只以自己的原始提示词为审美权威。

## 优先级与开场

1. 先解析本次调用。显式参数和清楚的描述永远覆盖记住的值。
2. 所有必需的交付变量都已确定时，跳过偏好问题直接继续。生成前保存本次新确定的安全偏好，除非用户选了 `--prefs off` 或明确说不要记住。
3. 仍有未确定项时，运行 `python3 scripts/shop_preferences.py load`（脚本路径相对当前 Skill 目录解析，不假设进程工作目录）。
4. 结果为 `missing` 或 `invalid` 时，不展示文件内容，也不当作任务失败，继续普通问询。
5. 有有效记录时，展示一段简短摘要，并问一个真正的单选题：

```text
检测到上次的 XXD Shop 交付偏好：
尺寸：<尺寸策略／比例／像素>
张数：<每个尺寸几张>
文字：<方式与语言；准确文案时写“准确文案需本次重新输入”>
输出：<自定义根目录或默认>

这次怎么开始？
1. 直接沿用——沿用上次设置，本次已经说出的要求优先
2. 沿用并修改——先带入上次设置，只改我指定的项
3. 全新配置——忽略上次设置，从头选择
```

宿主有单选工具时用单选工具；没有时用上面的编号文字题，作为打字选择，不画假复选框。

## 三个选项的含义

- **直接沿用：** 用记录填补未确定的字段，本次显式要求优先。只追问不能安全沿用的值，例如新的准确文案。
- **沿用并修改：** 带入记录后，问要改哪些字段：尺寸、张数、文字／语言、输出根目录。有真正的多选就用多选，否则接受打字组合。未选中的字段保持不变，只问选中的。
- **全新配置：** 本次忽略记录，走普通问询。不立即删除旧记录；新设置完整确定后再替换，避免中途取消时丢掉有用的偏好。

部分行内参数不会跳过这个选择：它们覆盖对应字段，其余字段由所选路线决定。

## 行内偏好控制

调用后任何位置都可以写 `--prefs`：

- `--prefs last`：不问三选一，直接沿用；
- `--prefs edit`：带入记录，只问要改什么；
- `--prefs new`：忽略记录，全新配置；
- `--prefs off`：本次忽略记录，也不保存本次；
- `--prefs clear`：清除记录后全新配置，确定后保存新的偏好，除非用户同时说不要记住。

`last` 或 `edit` 但没有有效记录时，简短说明后改走全新配置。“沿用上次设置”“在上次基础上改”“这次重新选”“不要记住这次”等说法含义相同。

## 保存

本次交付设置完整且一致后，只用 `python3 scripts/shop_preferences.py save ...` 保存安全字段（同样相对当前 Skill 目录解析）。尺寸可以重复或逗号分隔。不把准确文案或任何禁止字段传给脚本。

只保存用户本次真正选择的字段。原稿或覆盖条款固定的值（例如 012 的 16:9 像素、013 由原稿规定的英文手写）不写进记录，免得污染其他编号；本次没有选择语言时不保存语言，下次需要文字时再问。

`auto` 记为策略 `auto`，不记上次按某件商品算出的比例；`source` 记为 `source`，不记上次原图的尺寸。自定义输出根目录只在仍然可用时沿用；不可用时只把这一项当作未确定。

目录批量只保存公共交付设置，不保存个别例外和文件名到文案／事实的映射。总指挥 `xxd-shop-all` 不保存推荐方式、所选编号、试稿组合、套图位置或分派策略，只保存最终交给士兵的交付设置；它派出的单子带 `--prefs off`，由总指挥在全部派完后统一保存一次。
