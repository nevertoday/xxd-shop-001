# 样张制作流程

本文件只用于维护样张，不是运行前提。打包与文档检查从不调用图像模型。

用户要求制作样张时：

1. 使用用户提供的商品图或明确给出的商品名称，以及本编号完整的原始提示词。没有商品素材时先向用户要；不借用其他编号的成品，不编造不存在的参考图。商品图要有使用授权，不用他人品牌的未授权商品冒充本项目样张。
2. 一次确定张数、尺寸与文字方式。每张样张都是一次完整画布生成；不默认批量、不自动出变体、不做拼贴总览、不自动重试。
3. 按 `SKILL.md` 与 `references/shop-runtime.md` 执行，尤其是事实纪律：样张上的价格、规格、产地等事实同样必须来自素材本身或用户提供。
4. 逐张目视检查商品身份、包装文字、原稿审美与文字层级；只看尺寸不能代替目视验收。用 `xxd-strip-ai-meta` 清理受支持的来源元数据，不改像素；不声称这样就“不是 AI 作品”。
5. 只有目视通过的真实成品才放进 `assets/examples/`，并在 `assets/examples/README.md` 记录：文件名、来源素材、尺寸、文字方式与 `visual_review: passed`。失败的结果不进图库。
6. 更新 README 的样张部分，链接到真实文件，删掉“暂无样张”的说明。

不添加不存在的样张链接，不把商品原图当成生成样张，不把其他编号的作品当作本编号的样张。样张只是文档证据，运行时永远不能替代原始提示词。
