# 🦁 XXD Shop 001｜ハイエンド商業メインビジュアル

### 商品そのものから、静かでリアルで空気感のあるブランドの世界を育てる

<a href="README.md">简体中文</a> · <a href="README.en.md">English</a> · <strong>日本語</strong> · <a href="README.ko.md">한국어</a> · <a href="README.ar.md">العربية</a>

</div>

**ふつうの商品写真を、成熟したブランドが撮ったような EC メインビジュアルに。**
商品自体は一切変えずに、光・置き場所・環境・色を組み直し、「貼り付けた感」をなくします。

| ひと目で分かる | |
|---|---|
| **渡すもの** | 商品画像（白背景・実物写真・パッケージ写真どれでも可）、または商品名だけ |
| **受け取るもの** | EC メイン画像、商品詳細ページのファーストビュー、ブランド KV、スプラッシュ画面、バナー。サイズごとに構図を作り直した PNG |
| **スタイルの特徴** | 重さのある商品 · リアルな接地と接触影 · やわらかな指向性の光 · 商品から生まれる環境色 · たっぷりの余白 · タイトルはあってもなくても |
| **向いている用途** | セール感ではなく、静かで上質なブランド感がほしい商品画像 |

> **インストールしたら、こう言うだけ：**
>
> /xxd-shop-001 うちのコールドブリューです。メイン画像と詳細ページのファーストビューを作って

## 解決すること

多くの商品画像の問題は「ダサい」ことではなく、商品が貼り付けたように見えることです。浮いている、光がのっぺりしている、安っぽい台座、背景が主役を奪う、パッケージの文字を AI が勝手に書き換えている。

**Shop 001** がやることはひとつ。商品はそのままに、光・置き場所・環境・色を組み直して、成熟したブランドのメインビジュアルに見せます。

- **商品写真があり、ブランド品質の画像にしたい：** 形、パッケージの文字、ロゴはそのまま残します。
- **商品名やアイデアしかない：** カテゴリ・素材・用途・性格から、ありそうな商品と世界を組み立てます。
- **セール感ではなく、静かで上質にしたい：** 背景は控えめ、小物は商品を説明するものだけ、タイトルは希望するときだけ。
- **1つの商品を複数サイズで：** 1:1 メイン画像、3:4 詳細ページ、9:16 スプラッシュ、16:9 バナー。比率ごとに構図を作り直し、別の画像から切り抜くことはありません。

## 似たスタイルとの選び分け

| ほしいもの | 使うもの |
|---|---|
| 静かで空気感のある、ブランド主導のメイン画像 | **001**（このスタイル） |
| 価格とメリットがひと目で伝わるセール画像 | [009 高コンバージョン・メインビジュアル](https://github.com/nevertoday/xxd-shop-009) |
| 手元の写真を広告品質に作り直し、光で機能を表現 | 011 製品ビジュアル再構築 |

## 用意するもの

- **商品画像**（推奨）：商品全体が写った1枚で十分。ディテールや別アングルがあるとより安定します。
- **または商品名：** 写真がなければ、カテゴリと素材から商品を組み立てます。
- **用途**（推奨）：「メイン画像」「詳細ページのファーストビュー」「ブランド KV」など。ここからサイズを提案します。
- **価格・仕様・産地**（任意）：画像に載せたいときだけ伝えてください。伝えていないものは出てきません。

## 使い方

### ステップ 1：インストール（1回だけ）

```bash
git clone https://github.com/nevertoday/xxd-shop-001.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-001" ~/.claude/skills/xxd-shop-001
```

Codex を使う場合は、同じフォルダを `~/.codex/skills/xxd-shop-001` にリンクしてください。インストール後は AI アシスタントのセッションを再起動します。

### ステップ 2：やりたいことを普通の言葉で言う

```text
/xxd-shop-001 うちのコールドブリューです。メイン画像と詳細ページのファーストビューを作って
/xxd-shop-001 商品名だけです：手作りの青梅酒、500ml ガラス瓶。4:5 のブランドポスター、文字なしで
/xxd-shop-001 ~/Desktop/products の商品すべてに 1:1 のメイン画像を作って
```

覚えるフラグはありません。サイズや枚数など決めていないことは一度にまとめて質問され、次回は前回の設定を再利用できます。

### ステップ 3：そのあと何をするか

1. 商品画像と説明を読み、まだ決まっていないことだけを質問します。サイズは用途から、ピクセル数付きで提案します。
2. サイズごとに構図を新しく作り、別の画像から切り抜くことはありません。
3. 納品前に1枚ずつ確認します。商品は変わっていないか、文字のつづりは正しいか、渡していない数字はないか。通らないものは報告して作り直します。
4. PNG を `~/Desktop/xxd/xxd-shop-001/` の下の新しいタスクフォルダに保存し、パスを伝えます。

| フラグ | 用途 |
|---|---|

| `--use "..."` | 掲載場所：メイン画像、詳細ページ、ポスター、ブランド KV、SNS、バナーなど |

## よくある質問

**タイトルは必要ですか？**

いいえ。このスタイルはタイトルなしでも成立します。決まった一文を入れたいときは、その文言を渡せばそのまま使います。

**何が必要ですか？**

3つです。① Claude Code や Codex など、Skills に対応した AI アシスタント。② 画像を生成できるモデル。アシスタント内蔵の画像生成、または Codex に設定したモデルプロバイダーで Responses API 経由で画像を生成するもの（既定は GPT Image 2）。③ Pillow 入りの Python 3.11 以上（`pip install pillow`）。

**お金はかかりますか？商用利用できますか？**

Skill は無料でダウンロードできます。画像生成の費用はあなた自身のモデルアカウントに請求されます。本プロジェクトは PolyForm Noncommercial ライセンスです。個人の学習・研究・テストには使えますが、ショップ運営、受託制作などの商用利用には事前に作者の書面による許可が必要です。末尾の「ライセンス」を参照してください。

**画像の大きさは？**

比率か正確なピクセル数を指定できます。実際のサイズはモデルが返したとおりで、こっそり拡大することはなく、ファイル名に本当のピクセル数が書かれます。

**画像内の文字に誤字は出ますか？**

AI の画像では、ときどき文字を間違えたり、ブランド名の横に ® のような小さな記号を足したりします。納品前に1枚ずつ拡大して確認し、通らないものは作り直します。このページの作例はすべてその確認を通っています。

**価格や販売数をでっち上げませんか？**

しません。価格、仕様、産地、販売数、受賞、認証など事実に見えるものは、あなたが提供したものか、商品にはっきり読める文字からだけ取ります。それ以外は載せず、「¥XX」の仮置きもしません。

**たくさんの商品を一度に処理できますか？**

できます。商品画像のフォルダを渡してください。1枚の画像に商品1つ、サイズと文字は一度だけ質問され、ある商品の事実やコピーが別の商品に混ざることはありません。
